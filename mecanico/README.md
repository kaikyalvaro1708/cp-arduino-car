# Arquivos mecânicos

Pasta para os arquivos de modelagem e fabricação do chassi e da carenagem.

| Tipo | Exemplo de nome |
|---|---|
| Arquivo-fonte (Fusion 360, Tinkercad, Inkscape...) | `chassi_v1.f3d`, `chassi_v2.f3d` |
| Arquivo para fabricação | `chassi_v2.stl` / `chassi_v2.dxf` |
| Carenagem | `carenagem_v1.stl` |

Detalhes do projeto mecânico em [docs/02-projeto-mecanico.md](../docs/02-projeto-mecanico.md).
